# Anime Maker Demo MVP

A modular smart-illusion AI animation pipeline designed for automated media generation and processing.

## Architecture Departments
1. Animation: Visual frame generation via Hugging Face API.
2. Fixer: Quality control and error handling via Google Gemini and Groq AI.
3. Converter: Final media assembly and conversion via Cloudinary API.

## Installation and Execution
Run the following commands in your terminal:
```bash
pip install -r requirements.txt
python main.py
